# Dartvexo– Offline Edition

**Deine Dart-Trainingsplattform. Deine Regeln. Keine Cloud.**

DartForge ist eine browserbasierte Trainingsplattform für Dartspieler. Die Anwendung ist auf die Nutzung am PC, Laptop und Smartphone ausgelegt.

## Funktionen

- X01 von 101 bis 901
- Solo-, lokaler Zwei-Spieler- und Bot-Modus
- Dart-Tic-Tac-Toe mit individuellen Aufgaben
- Checkout-Trainer
- Lokale Statistiken und Spielverlauf
- Dunkles Neon-Design
## Datenschutz

DartForge benötigt keine Registrierung, kein Benutzerkonto und keinen Cloud-Speicher. Persönliche Daten und Spielstände werden lokal im Browser gespeichert.

**Achtung:** Beim Löschen der Browserdaten oder beim Wechsel auf ein anderes Gerät können lokale Daten verloren gehen. Erstelle regelmäßig ein Backup. (ES WIRD KEINE HAFTUNG ÜBERNOMMEN BEI DATEN VERLUSST)

DartForge befindet sich in Entwicklung. Einzelne Spielfunktionen und Trainingsmodi müssen noch getestet und verbessert werden. Externe Dienste wie Online-Multiplayer sind nicht verbunden.
